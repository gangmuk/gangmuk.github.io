Koi is a self-calibrating scheduler for LLM inference clusters. It treats each deployment as an experiment, tests causal hypotheses about why each deployment performs as it does, and uses what holds to plan every job, including jobs it has never run.

The interactive project page is here: [gangmuk.github.io/koi](/koi/).

- Paper: [arXiv 2610.24355](https://arxiv.org/abs/2610.24355)
- Code: [github.com/Tandemn-Labs/tandemn-koi](https://github.com/Tandemn-Labs/tandemn-koi)
